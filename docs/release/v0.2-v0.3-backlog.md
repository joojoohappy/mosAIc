# mosAIc v0.2–v0.3 backlog

Items found during the v0.1 release work that are deliberately not in v0.1. Nothing here has been started.

## v0.2: harden what v0.1 ships

| Item                                          | Why                                                                                             |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Scheduled deletion of expired results         | Results stop being served after 30 days but stay in storage; a daily job should delete them.    |
| Atomic global budget                          | Today's read-then-write counter can overshoot slightly under parallel load (e.g. a KV counter). |
| Shared per-visitor counters                   | Per-visitor limits are per server instance.                                                     |
| Delete-my-result button                       | Lets a visitor remove a result without contacting anyone.                                       |
| Private contact for privacy requests          | `/privacy` currently points to GitHub Issues.                                                   |
| `<h1>` on "recipe not found"                  | Last axe "moderate" finding.                                                                    |
| Lighthouse + screen-reader pass on production | Automated checks ran on a local build only.                                                     |
| Lock transitive Python dependencies           | Direct dependencies are pinned; a lock file (e.g. `uv lock`) would pin the rest.                |
| Live usage view for the owner                 | Today's usage is a JSON file in storage (`meta/usage-YYYY-MM-DD.json`).                         |
| More verified recipes                         | Only three seeds exist, none open for Try yet.                                                  |

## v0.3: product

| Item                                     | Why                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------- |
| Creator submission and verification flow | Out of scope for v0.1; today recipes are added by editing `recipes.json`. |
| Report / moderation for results          | Needed once usage grows.                                                  |
| Real creator previews (before/after)     | `previewBeforeUrl` exists in the data model but is unused.                |
| Expo mobile app on the shared packages   | `apps/mobile` is a placeholder.                                           |

## Still out of scope

Login, payments, social features, recommendations and bring-your-own AI providers stay out until the owner decides otherwise.
