# mosAIc v0.1 action items

Derived from [the gap audit](v0.1-gap-audit.md). **P0** blocks a public release, **P1** should land before or right after it, **P2** can wait for v0.2. "Owner" items need someone with access to Vercel, Google AI Studio or the recipe creators; they cannot be done from the repository.
