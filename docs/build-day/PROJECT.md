# AI Creative Playground｜Prototype 簡介

## 這次要做什麼

整理社群媒體上創作者自己反覆測試、調整並分享的圖片生成 prompt，集中呈現，讓更多人容易找到、直接試用，也能回到原作者的頁面交流，體會 AI 創作的樂趣。

## 使用者可以怎麼用

1. 瀏覽整理好的 prompt 和**原作者提供的生成圖預覽**。
2. 點進一份 prompt，看原始貼文，並**一鍵前往原作者 IG**（有確認連結時）。
3. 上傳自己的照片，在平台內直接套用這份 prompt 生成圖片，不必自己複製文字、切換 AI 工具。
4. 查看生成結果，以及這份 prompt 的來源與創作者。

## Build Day 的範圍

先用目前選出的三份 prompt 做出一條能展示的體驗。看完 Fable5 demo 後，三位 builder 再決定畫面、技術、分工，以及要優先展示哪個互動。**目前討論的流程是起點，不是固定規格。Current hypotheses are not requirements.**
